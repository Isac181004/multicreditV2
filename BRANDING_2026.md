# Branding Multicredit 2026

Paleta corporativa aplicada a la web pública y al panel administrativo.

| Uso | Color |
|---|---|
| Azul marino principal | `#0B1F3A` |
| Azul marino secundario / hover | `#163A5F` |
| Azul marino profundo | `#071525` |
| Gris principal | `#6B7280` |
| Gris oscuro | `#374151` |
| Gris de borde | `#D1D5DB` |
| Gris de fondo | `#F3F4F6` |
| Blanco | `#FFFFFF` |
| Negro | `#0A0A0A` |

El archivo `css/mc-brand-2026.css` es la capa global de marca. Los nombres de variables heredados (`--mc-green`, `--mc-orange`, `brand-green`, etc.) se mantienen solo como alias de compatibilidad, pero sus valores ya pertenecen a la nueva paleta.
